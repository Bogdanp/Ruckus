# Build 8

## Added

- Package management UI with search, install, and remove.
- Clean button to remove orphaned auto-installed dependencies.
- Allow removing auto-installed dependencies.
- Show loading indicator during package search.
- Disable install/remove buttons while an operation is in progress.
- Support writable Racket package installation.

## Changed

- Minimize bundled distribution by removing unneeded packages.
- Strip doc metadata files (~44MB savings).

## Fixed

- Guard against concurrent package list loads and ignore cancellation errors.
- Don't cancel remove task when swipe action disappears.
