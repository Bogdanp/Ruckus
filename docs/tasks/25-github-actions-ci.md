# Set up GitHub Actions CI

## Summary

The project has no CI. Regressions are only caught by building locally. A
GitHub Actions workflow should run lint, build, and tests on every push and
pull request so problems are caught before merge.

## Current Build Requirements

The build has several non-trivial dependencies that CI must account for:

### Racket toolchain (`bin/pbraco`)

The pre-build `make` step compiles Racket sources into `Ruckus/res/core.zo`
and generates `Ruckus/Backend.swift` via `bin/pbraco`. This requires a
working Racket installation with the project's custom tooling.

### Local `Noise` dependency

`Tuist/Package.swift` references `Noise` via a relative path:

```swift
.package(path: "../../Noise")
```

CI needs to clone the Noise repo and place it at the expected relative path
(or override the dependency to use a Git URL).

### Tuist

The Xcode project is generated by Tuist (`tuist generate --no-open`). CI
must install Tuist before building.

### Xcode / iOS SDK

`Project.swift` targets iOS 26.0 with Swift 6.0. CI needs a macOS runner
with Xcode 26.2+ (`macos-15` or later GitHub-hosted runner, once available,
or a self-hosted runner).

## Suggested Fix

Create `.github/workflows/ci.yml` with two jobs:

### Job 1: Lint

Runs `swiftlint lint` on the Swift sources. This is fast and has no Racket
dependency.

```yaml
lint:
  runs-on: macos-15
  steps:
    - uses: actions/checkout@v4
    - run: brew install swiftlint
    - run: swiftlint lint --strict
```

### Job 2: Build & Test

```yaml
build:
  runs-on: macos-15
  steps:
    - uses: actions/checkout@v4
    - name: Clone Noise
      uses: actions/checkout@v4
      with:
        repository: <owner>/Noise
        path: ../Noise
    - name: Install Tuist
      run: brew install tuist
    - name: Install Racket
      run: brew install minimal-racket
    # Install any raco packages needed by bin/pbraco
    - name: Generate backend
      run: make
    - name: Generate project
      run: tuist generate --no-open
    - name: Build
      run: |
        xcodebuild build -workspace Ruckus.xcworkspace -scheme Ruckus \
          -destination 'generic/platform=iOS' | xcpretty
    - name: Test
      run: |
        xcodebuild test -workspace Ruckus.xcworkspace -scheme Ruckus \
          -destination 'platform=iOS Simulator,name=iPhone 17 Pro' | xcpretty
```

### Open Questions

- **Racket setup:** `bin/pbraco` wraps Racket with project-specific config.
  CI needs to replicate the local Racket environment — this may require
  installing specific raco packages or vendoring compiled artifacts.
- **Noise repo access:** if Noise is private, the workflow needs a deploy key
  or token. Alternatively, the `Package.swift` path could be overridden in CI
  to use a Git URL.
- **Runner availability:** iOS 26 SDK requires Xcode 26.2. If GitHub-hosted
  runners don't have it yet, a self-hosted runner is needed. An interim option
  is to run only lint and skip the build until runner support catches up.
- **Caching:** Tuist fetch, Racket compilation, and DerivedData are all
  cacheable to speed up builds.
