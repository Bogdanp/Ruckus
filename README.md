# Ruckus

Racket for iOS.

## Build

### Requirements

* [Racket 9.1 CS](https://racket-lang.org/)
* [Noise](https://github.com/Bogdanp/Noise)
* macOS Sequoia
* Xcode 26+

### First-time Setup

    $ raco pkg install --name ruckus-core/

### Building

    $ make
    $ tuist generate
    $ tuist xcodebuild build
